# RCircos: R package for Circos 2D track plot

The RCircos is a personal forked version. We've made some improvements to the original code, as follows:

-   Bug fixes
-   Make documentation available online

Online documentation

-   [Get started](https://caotianze.github.io/RCircos/articles/RCircos.html)
-   [Documentation](https://caotianze.github.io/RCircos/reference/index.html)

Installation
```R
if (!requireNamespace("devtools", quietly=TRUE))
    install.packages("devtools")
devtools::install_github("CaoTianze/RCircos")
```
